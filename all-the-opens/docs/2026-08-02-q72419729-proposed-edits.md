# Proposed Wikidata edits: Q72419729 (Prandtl's 1899 dissertation)

Date drafted: 2026-08-02 · Status: **draft, nothing submitted**
Account that would make them: `LuisVilla` (manual, via the UI — no bot flag needed)

## Why these are Wikidata edits, not Internet Archive edits

The gap is on the Wikidata side. The Internet Archive's record is fine: it has a
title, a creator, a date, a publisher and a collection, and we could not edit it
anyway — we didn't upload it and don't hold the item.

What's missing is on Wikidata: the item describes a thesis but does not say what
it is called in English or German, and **does not point at the scan**. That last
one is the edit that matters. Today the two records share no identifier, which is
why the page has to corroborate the match from three agreeing values. Adding the
Internet Archive ID to the Wikidata item converts that permanently into an
identifier match — for us and for everyone else's tools, forever after.

## The title, read off the scan

Source: title page OCR of `archive.org/details/IA41548318_0126`
(collections: `theses-and-dissertations`, `leiden-university`).

```
KIPP-ERSCHEINUNGEN.
EIN FALL
VON INSTABILEM ELASTISCHEM GLEICHGEWICHT

INAUGURAL-DISSERTATION
DER PHILOSOPHISCHEN FAKULTÄT, SEKTION II
DER LUDWIGS-MAXIMILIANS-UNIVERSITÄT ZU MÜNCHEN.
EINGEREICHT AM 14. NOVEMBER 1899
VON LUDWIG PRANDTL, GEPRÜFTER MASCHINEN-INGENIEUR.
NÜRNBERG. KOMMISSIONSVERLAG DER V. EBNER'SCHEN BUCHHANDLUNG.
```

So the Internet Archive's title, `Kipp-Erscheinungen`, is the **short form** — it
drops the subtitle. The full title is
*Kipp-Erscheinungen: ein Fall von instabilem elastischem Gleichgewicht*
("Tipping phenomena: a case of unstable elastic equilibrium" — the subject is what
is now called lateral-torsional buckling).

## Proposed edits

### 1. `label[de]` — the title in its own language

```
Kipp-Erscheinungen : ein Fall von instabilem elastischem Gleichgewicht
```

### 2. `label[en]`

```
Kipp-Erscheinungen : ein Fall von instabilem elastischem Gleichgewicht
```

The original title, not a translation. The work has no established English title,
and inventing one would be worse than leaving it in German — English Wikidata
labels for foreign-language works conventionally keep the original.

*Open question for you:* both labels use the spaced colon of the existing Catalan
label rather than `Kipp-Erscheinungen: ein Fall…`. The spaced form is library
cataloguing convention (and matches its sibling record); the unspaced form is
ordinary German typography. I'd match the Catalan for internal consistency, but
it's a coin-flip.

### 3. `description[en]`

```
1899 doctoral dissertation by Ludwig Prandtl
```

### 4. `description[de]`

```
Dissertation von Ludwig Prandtl (1899)
```

### 5. `P724` (Internet Archive ID) — **the one that actually matters**

```
P724 = IA41548318_0126
```

This is the edit that removes the need for corroboration. After it, any tool
joining Wikidata to the Internet Archive finds this thesis by shared identifier,
the way it finds a book with an ISBN.

### 6. `P1476` (title) — optional

```
P1476 = "Kipp-Erscheinungen : ein Fall von instabilem elastischem Gleichgewicht" (de)
```

Records the title as a monolingual claim rather than only as a label. Nice-to-have;
the labels carry the weight.

## Deliberately not proposed

- **Changing `P577`.** The scan says *eingereicht am 14. November 1899* — the
  submission date, which is not the publication date `P577` means. The existing
  `1899` is right; a spurious precision would be a regression.
- **Anything sourced only to our own render.** Each edit above traces to the scan's
  title page or to the IA record, both citable.

## What happens to the demo if these land

The corroborated card for this thesis would become an ordinary identifier match,
and the dashed styling and its legend would stop appearing on the Prandtl page.
That is the correct outcome and should not be worked around: `corroborate.js` must
keep its fallback, because the great majority of described-objects it meets will
still have no identifier. If we want the page to keep demonstrating the
corroborated class after fixing this item, the honest move is to find another
unlinked thesis in the same collection, not to preserve this one's gap.
